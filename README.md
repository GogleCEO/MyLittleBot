ВК бот по теме исторический детектив.
Предоставляет возможность тренировочного режима с выбором эпох: новое время, среднивековье, античность или все.
По выбранным эпохам выбирается случайная тема из википедии через API. пользователь должен выбрать правильный ответ из 4х вариантов по описанию события/личности/государства или по изображению.
Доступен соревновательный режим. Два игрока отвечают на 5 вопросов и выводится победитель, тот, кто ответил на большее число вопросов.
Победителю присваивается рейтинг, проигравшему уменьшается. Значение рейтинга для каждого пользователя хранится в базе данных на сервере.

Запуск бота происходит через запуск скрипта main.py. 
Ключ доступа к боту хранится в файле .env
Для работы с API вк используется библиотека vkbottle
Для работы с API Википедии используется wikipedia-api
